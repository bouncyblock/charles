# Charles
## Multi-purpose AI Discord Bot
![hackatime badge](https://hackatime-badge.hackclub.com/U09GRHV7Y80/charles)

CURRENTLY WIP but if you want to try:

1. Clone main
2. Install python 3.11.14
3. Install reqs from requirements.txt
4. Add things to your .env
5. Run main.py

Your .env should look like this:

```.env
11LABS_API_KEY=""
11LABS_VOICE_ID=""
AI_API_KEY=""
DISCORD_API_KEY=""

```

Your AI api key should come from [ai.hackclub.com](ai.hackclub.com), as thats the only key I've tested.
